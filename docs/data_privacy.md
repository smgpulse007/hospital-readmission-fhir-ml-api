# Data Privacy

This repository uses synthetic, toy data only.

It does not contain:

- protected health information
- personally identifiable information
- employer-confidential assets
- proprietary claims workflows
- production credentials
- real patient, member, provider, or payer records

The API and examples are designed for public portfolio review and local demonstration. Any real deployment would require formal data governance, HIPAA/security review, model risk management, and clinical workflow validation.
